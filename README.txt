MAGIC ART STICKER CALCULATOR - PWA PACKAGE

How to install and run this PWA:
1. Extract all files (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) into a single folder.
2. To test the PWA installation prompt properly:
   - On your computer: Open it via a local web server (like VS Code Live Server or Python's `python -m http.server`), OR
   - Upload the folder to any free hosting provider like Netlify, Vercel, or GitHub Pages (which supports HTTPS).
3. Once opened in Chrome/Edge/Safari, click the browser menu or the "Install App" option to add it directly to your mobile home screen or computer desktop!
